# Gachinetes ♂ — дизайн

Gachinetes — дистрибутив Kubernetes, пересобранный вокруг мема гачимучи.
Мем даёт словарь, а каждый термин закрывает настоящую дыру Kubernetes.
Основа — [kuberoot](https://github.com/kuberoot-dev/kuberoot), надстройки
поставляются пакетами [kubepkg](https://github.com/kuberoot-dev/kubepkg).

Три слоя, все остаются:

1. **Язык** — имена, CLI, события, логи, интерфейс. Сам мем.
2. **Надстройки** — контроллеры, вебхуки и веб-приложение поверх любого кластера.
3. **Ядро** — изменения в хранилище, apiserver, планировщике и kubelet.

## Ядро

### Кассета: хранилище как журнал

Kubernetes сжимает историю etcd, и прошлое состояние кластера теряется.

Кассета — хранилище, совместимое с API etcd (тот же подход, что у kine,
который уже стоит в kuberoot). apiserver говорит с ней как с etcd, поэтому
watch, информеры и все существующие контроллеры работают без изменений.
Внутри:

- каждая ревизия хранится в журнале, который только дописывается;
- свежие ревизии отдаются из горячего слоя, старые сегменты уходят в объектное хранилище;
- запросы на сжатие от apiserver обрезают только горячее окно.

Это даёт:

- **Перемотку** — чтение кластера на любой ревизии или момент и сравнение
  двух моментов (`gachictl rewind --to 2026-10-29T13:00Z`).
- **Воспроизведение** — повтор потока событий инцидента.
- **Кладбище** — удалённые объекты остаются читаемыми и восстановимыми.
- **Аудит** без отдельного конвейера.

### Rest in peace: отменяемое удаление

Удаление переносит объект на кладбище на время хранения, а не стирает его.
Новый подресурс восстанавливает: `gachictl undelete ns/prod --as-of 5m`.
Восстановление идёт в порядке владения: сначала владелец, потом зависимые.
Кладбище — обычный API только для чтения.

### Deep dark fantasies: ветки состояния

`--dry-run=server` проверяет один объект, и никто не знает, что в ответ
сделают контроллеры, планировщик и автоскейлеры.

Фантазия — ветка кассеты от ревизии с копированием при записи. Gachinetes
поднимает для ветки отдельный apiserver с настоящими планировщиком и
контроллер-менеджером, применяет изменение и ждёт затишья. Результат — отчёт:
новые и изменённые объекты, размещения, вытеснения, изменение стоимости.
Фантазию можно слить (её записи повторяются на основной ветке с проверкой
конфликтов) или выбросить.

```
gachictl fantasize -f upgrade.yaml --until-quiet 5m
```

В ветке настоящие контейнеры не запускаются: kubelet ветки симулирован.

### Пояса: владение полями в apiserver

Сейчас конкуренция оптимистичная (`resourceVersion`, 409, повтор), а
server-side apply с `--force` просто забирает поле. Войны контроллеров
заложены в модель.

В Gachinetes у каждого поля есть держатель пояса — менеджер полей, который им
владеет. Писать поле может только он. Остальные бросают **вызов**, и apiserver
решает по политике (`BeltPolicy`: приоритет менеджера, явная передача,
живость держателя). Каждая смена титула записывается на кассету.

Итог: нет войн контроллеров, нет штормов повторов на 409, у каждого поля
читаемая история владения.

Внедрение: сначала детектор и ValidatingAdmissionPolicy, потом
принудительное соблюдение в менеджере полей apiserver.

### Sorry for what?: причинность в метаданных

`ownerReferences` говорят, кто владеет объектом, но не что стало причиной
изменения.

Каждая запись несёт цепочку причин (W3C `traceparent` плюс объект-причина и
ревизия). Клиентские библиотеки контроллеров Gachinetes пробрасывают её сами;
для upstream-контроллеров apiserver выводит её из события информера,
предшествовавшего записи. Любой сбой объясняет себя проходом по цепочке:
правка Deployment → ReplicaSet → Pod → вытеснение командой X.

### Safeword: эпохи доверия

Токены сервис-аккаунтов — JWT, мгновенно отозвать выданный токен почти
невозможно.

apiserver хранит **эпоху доверия**. Каждый повышенный доступ привязан к
эпохе выдачи. Стоп-слово (`gachictl safeword`) поднимает эпоху, и все
повышенные сессии умирают сразу. Повышение — объект `Contract`: объём, срок,
стоп-слово, одобрения.

### Страхующий: правило двух человек

Опасные операции (удаление неймспейса, CRD, PV; контракты cluster-admin;
правка боевой BeltPolicy) требуют страхующего: вторая идентичность одобряет
в течение окна. Проверяется в admission, записывается на кассету.

## Планирование и исполнение

### Весовые категории

Классы QoS становятся весовыми категориями: наилегчайший вес (BestEffort),
средний (Burstable), тяжёлый (Guaranteed) и новый **супертяжёлый** —
эксклюзивная нода или целые GPU. Вытеснение — только внутри категории или
сверху вниз, правила боя всегда видны.

### Tag team: групповое планирование в ядре

`Team` — первоклассная группа подов. На ринг выходят все или никто:
распределённое обучение не висит на 60 из 64 GPU. Команду можно разложить
по топологии (NVLink-домен, стойка, зона).

### Three hundred bucks: деньги как единица

- Цены `ResourceClass` (по модели GPU, CPU, памяти, классу хранения).
- `Budget` на неймспейс в валюте вместо ядер.
- При нехватке ресурсов поды делают ставки из бюджета. Вытесненный под
  получает кредиты и первым встаёт в очередь.
- `apply` показывает изменение стоимости до применения. Ручные действия
  (`exec`, `port-forward`, правки руками) учитываются как ручной труд с ценой.

### Boy next door: размещение по трафику

Потоки из Cilium Hubble показывают, кто с кем говорит. Планировщик и
дешедулер ставят самые разговорчивые пары на одну ноду или в одну зону:
меньше задержек и счетов за межзональный трафик.

### Get your ass back here: живая миграция

Выселение по умолчанию означает перенос. Под переезжает на другую ноду с
памятью, IP и открытыми соединениями (CRIU через checkpoint API kubelet,
дополненный восстановлением). Drain без простоя; карантин Dungeon становится
живым переносом на изолированную ноду с сохранённой памятью.

### Раунды: долгие задачи с чекпойнтами

Долгая задача идёт раундами. Между раундами Gachinetes делает чекпойнт
(хук приложения или CRIU, где возможно). Вытесненная или перенесённая задача
продолжает с последнего раунда, а не с нуля.

### Протеин: прогретая ёмкость

Образы AI весят гигабайты, GPU-ноды подключаются минутами. Протеин держит
тёплые пулы нод, заранее тянет образы по прогнозу и использует ленивую
загрузку, чтобы контейнер стартовал до полной загрузки образа.

### Boss of this gym на каждый шард

Контроллеры шардированы. У каждого шарда свой босс, реплики борются за шарды
и забирают их у ослабевших. Лидер определяется по форме (задержка до etcd,
глубина очереди, частота ошибок), а не только по аренде, поэтому больного
лидера заменяют до падения.

## Надстройки

- **Детектор борьбы** — находит пары менеджеров, которые по очереди
  переписывают одно поле (пока пояса не включены и для кластеров без ядра).
- **GymAutoscaler** — in-place resize как программа тренировок: прогрессивная
  нагрузка мелкими шагами с отдыхом, личные рекорды, мышечная память на
  сезонные пики, разгрузочные недели, проверяющие, нужны ли ещё ресурсы.
- **Dungeon** — карантин вместо убийства: сеть закрыта кроме разбора, снимок
  файловой системы и логов, отладочный контейнер, выпускает только Dungeon Master.
- **Leather** — жёсткие умолчания: user namespaces, seccomp и AppArmor,
  корень только для чтения, сеть по умолчанию закрыта.
- **Раздевалка** — шкафчики секретов на нагрузку: ключи привязаны к TPM ноды
  и идентичности нагрузки, в хранилище секреты никогда не лежат открытыми.
- **Leather club is two blocks down** — 404 от ingress подсказывает ближайший
  маршрут: опечатка, тот же сервис в соседнем неймспейсе, старое имя.
- **♂right version♂** — только дайджесты; при CVE образ сам пересобирается на
  исправленной базе, с SBOM и подписью.
- **Спарринги** — хаос по расписанию (убийство подов, задержки, потеря ноды),
  ранг устойчивости сервиса и таблица команд.
- **Performance artist** — зеркалирование трафика на новую версию до выката.
- **Хореография** — прогрессивный выкат в ядре: канарейка, анализ и волны по
  кластерам одним объектом.
- **Аники** — агент-наставник (на базе агент-оператора kuberoot): ревьюит
  манифесты в admission, объясняет сбои по цепочке причин, предлагает
  исправления. Свои действия никогда не одобряет сам.
- **Выездной матч** — вынос команды в другой кластер по мешу (например, GPU
  из публичного облака), когда свой зал занят.

## Интерфейс

Кассета VHS из девяностых.

- Строчная развёртка, шум трекинга, таймкод в углу, экранное меню
  видеомагнитофона (`PLAY ▶ 00:13:37`), пиксельный шрифт.
- Две темы: **Gym** (кафель раздевалки, хром) и **Dungeon** (кожа, заклёпки,
  красный свет).
- **Зал** — ноды как стойки и скамьи, поды как атлеты; размер мышц —
  потребление ресурсов, переразмеренный под выглядит раздутым.
- **Ринг** — повторы боёв контроллеров и смен поясов на шкале времени.
- **Кнопки кассеты настоящие** — `◀◀` и `▶` перематывают кластер по кассете.
- **Данмаку** — события летят по экрану, как на Niconico, с фильтрами.
- **Чат** — алерты как Twitch-чат с эмоутами: gachiBASS — деградация,
  gachiHYPER — восстановление, gachiGASM — успешный релиз.
- **Ремикс** — озвучка по желанию: нагрузка ведёт басовую линию, ошибки
  становятся сэмплами в ритме.
- **Аники** — панель справки и помощника.

## CLI

`gachictl`: `take-it boy -f` (apply), `wrestle` (решить вызов за пояс),
`rewind`, `undelete`, `fantasize`, `safeword`, `dungeon`, `spot`, `remix`.

## План

1. База дистрибутива: профиль kuberoot `gachinetes`, каркас `gachictl`,
   пакеты kubepkg.
2. Кассета + кладбище + перемотка; первый VHS-интерфейс с настоящими кнопками.
3. Детектор борьбы, пояса как политика, цепочки причин.
4. Фантазии.
5. Планировщик: весовые категории, tag team, бюджеты и ставки, boy next door.
6. Kubelet: живая миграция, раунды, протеин.
7. Безопасность: эпохи доверия и контракты, страхующий, Dungeon, Leather, раздевалка.
8. GymAutoscaler, спарринги, Аники, выездные матчи.

Каждая фаза заканчивается conformance (дистрибутив обязан оставаться
сертифицированным Kubernetes) и живой проверкой на стенде. Тяжёлые сборки и
стенды — в CI или кластере воркшопов в Hetzner, не на ноутбуке.
